# 서울 아파트 전월세 시장 분석 및 가격 예측

## 1. 프로젝트 개요

본 프로젝트는 서울시 아파트 전월세 실거래 데이터를 활용하여
서울 임대시장의 가격 구조를 분석하고,
전세보증금 및 월세가격 예측 모델을 구축하는 것을 목적으로 한다.

단순한 데이터 시각화에 그치지 않고 다음 과정을 하나의 분석 Pipeline으로 구성하였다.

데이터 수집 및 정제
→ 탐색적 데이터 분석(EDA)
→ 통계적 가설 검정
→ Feature Engineering
→ 머신러닝 가격 예측
→ SHAP 기반 모델 설명
→ PostgreSQL 기반 SQL 분석

분석 과정에서는 관찰 데이터에서 나타난 통계적 관계를
직접적인 인과관계로 확대 해석하지 않는 것을 원칙으로 하였다.

# 4. 데이터 정제

가격 데이터의 특성을 고려하여
단순히 값이 크다는 이유만으로 Outlier를 제거하지 않았다.

초고가 전세 및 월세 거래는 실제 고가 아파트 거래일 가능성이 있으므로
명백한 오류라는 근거가 없는 경우 유지하였다.

또한 다음 데이터 역시 원본에서는 유지하였다.

- 지하층 거래
- 건축년도 결측 거래
- 계약기간 결측 거래
- 신규계약구분 결측 거래

월세 계약임에도 임대료가 0원인 74건은
원본 데이터에서는 유지하되 월세가격 분석 및 모델링에서는 제외하였다.

건축년도 결측 데이터 역시 유지하되,
건축연식이 필요한 분석에서는 제외하였다.

# 5. 탐색적 데이터 분석

## 5.1 전세가격 변화

서울 아파트 전세보증금 중앙값은 다음과 같이 나타났다.

| 연도 | 전세보증금 중앙값 |
|---|---:|
| 2023 | 46,000만원 |
| 2024 | 50,000만원 |
| 2025 | 52,500만원 |

단위면적당 전세보증금 중앙값:

| 연도 | 중앙값 |
|---|---:|
| 2023 | 644.2만원/㎡ |
| 2024 | 706.7만원/㎡ |
| 2025 | 727.7만원/㎡ |

2023년부터 2025년까지 전세가격 수준이
전반적으로 상승하는 패턴이 관찰되었다.


## 5.2 지역별 가격 차이

2025년 단위면적당 전세보증금 중앙값은
서초구, 강남구, 성동구, 중구, 용산구 등에서 높은 수준을 보였다.

2023년과 2025년을 비교했을 때
서울 25개 자치구 모두 단위면적당 전세보증금 중앙값이 상승하였다.

60~85㎡ 아파트만 별도로 비교한 경우에도
25개 자치구 모두 2023년 대비 2025년 전세보증금 중앙값이 상승하였다.

따라서 전체 가격 상승 패턴은
단순히 대형 면적 거래 비중 증가만으로 설명되지는 않았다.


## 5.3 건축연식과 가격

2025년 단위면적당 전세보증금 중앙값:

| 건축연식 | 중앙값 |
|---|---:|
| 0~4년 | 988.5만원/㎡ |
| 5~9년 | 971.5만원/㎡ |
| 10~19년 | 776.8만원/㎡ |
| 20~29년 | 673.7만원/㎡ |
| 30년 이상 | 592.7만원/㎡ |

건축연식이 오래될수록
단위면적당 전세가격이 낮아지는 패턴이 뚜렷하게 나타났다.


## 5.4 보증금과 월세

전체 월세 데이터를 단순 비교하면
보증금과 월세의 Spearman 상관계수는 약 +0.17로 나타났다.

그러나 60~85㎡로 면적을 제한하고
자치구별로 분석한 결과
서울 25개 자치구 모두 음의 상관관계를 보였다.

이는 고가 지역 및 대형 주택에서는
보증금과 월세가 동시에 높은 경우가 존재하여
전체 데이터의 단순 상관관계가 실제 계약 구조를 가릴 수 있음을 보여준다.

# 6. 통계적 가설 검정

## 6.1 H1. 자치구별 전세가격 차이

Kruskal-Wallis 검정 결과:

- H statistic: 157,921.5082
- p-value: < 0.001
- Epsilon squared: 0.3124

서울 25개 자치구 사이에는
단위면적당 전세가격 분포의 통계적으로 유의한 차이가 존재하였다.

또한 효과크기 역시 큰 수준으로 나타났다.

따라서 H1은 지지되었다.


## 6.2 H2. 건축연식과 전세가격

Spearman 순위상관분석 결과:

- Spearman rho: -0.4143
- p-value: < 0.001

건축연식이 증가할수록 단위면적당 전세가격이 낮아지는
중간 수준의 음의 관계가 나타났다.

따라서 H2는 지지되었다.


## 6.3 H3. 전용면적과 전세보증금

상관분석 결과:

- Pearson r: 0.6088
- Spearman rho: 0.6373
- p-value: < 0.001

전용면적이 증가할수록 전세보증금이 증가하는
비교적 강한 양의 관계가 나타났다.

따라서 H3는 지지되었다.


## 6.4 H4. 조건 통제 후 건축연식

지역, 전용면적, 층, 계약연도를 포함한
다중회귀분석 결과:

- building_age coefficient: -0.011911
- p-value: < 0.001
- R²: 0.6287

건축연식이 1년 증가할 때
전세보증금은 평균적으로 약 1.18% 낮아지는 관계가 관찰되었다.

다른 조건을 고려한 이후에도
건축연식과 전세가격 사이의 음의 관계가 유지되었다.

따라서 H4는 지지되었다.


## 6.5 H5. 보증금과 월세

다중회귀분석 결과:

- log_deposit coefficient: -0.2571
- p-value: < 0.001
- R²: 0.3871

자치구, 면적, 건축연식, 층, 계약연도를 고려했을 때
보증금이 1% 증가하면
월세가 평균적으로 약 0.257% 낮아지는 관계가 관찰되었다.

따라서 H5는 지지되었다.

# 7. 머신러닝 가격 예측

미래 데이터를 이용한 정보 누수를 방지하기 위해
Random Split 대신 시간 기준 분할을 사용하였다.

Train:

2023~2024년

Test:

2025년


## 7.1 전세 모델

Train:

266,848건

Test:

238,570건

비교 모델:

- Median Baseline
- Ridge Regression
- Random Forest
- XGBoost

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Median Baseline | 24,418.73 | 38,372.88 | -0.0898 |
| Ridge Regression | 11,750.89 | 21,799.32 | 0.6483 |
| Random Forest | 10,085.60 | 16,266.84 | 0.8042 |
| XGBoost | **9,074.27** | **14,690.37** | **0.8403** |

최종 모델은 XGBoost로 선정하였다.

Median Baseline 대비 MAE는 약 62.84% 감소하였다.


## 7.2 월세 모델

Train:

185,103건

Test:

183,778건

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Median Baseline | 75.15 | 131.83 | -0.1049 |
| Ridge Regression | 57.81 | 169.70 | -0.8308 |
| Random Forest | 29.88 | 59.86 | 0.7722 |
| XGBoost | **29.32** | **57.68** | **0.7885** |

월세 역시 XGBoost가 가장 높은 성능을 보였다.

Median Baseline 대비 MAE는 약 60.98% 감소하였다.


## 7.3 Ridge 월세 모델의 한계

월세 Ridge Regression에서는
MAE는 Baseline보다 개선되었지만
RMSE와 R²가 크게 악화되는 현상이 나타났다.

오차 분석 결과 일부 특이한 주택 조건에서
실제 최대 월세가 4,000만원인 반면
약 16,048만원까지 예측하는 극단적인 과대예측이 발생하였다.

Tree 기반 모델에서는 이러한 현상이 크게 완화되었다.

이는 월세가격과 Feature 사이에
강한 비선형 관계와 Feature 간 상호작용이 존재함을 시사한다.

# 8. SHAP 모델 설명

최종 XGBoost 모델의 예측 구조를 설명하기 위해
SHAP 분석을 수행하였다.


## 8.1 전세 모델

Feature 중요도 순위:

1. 임대면적
2. 자치구
3. 건축연식
4. 법정동
5. 시간추세

임대면적이 증가할수록
전세가격 예측을 높이는 방향의 SHAP 값이 나타났다.

건축연식은 오래될수록
전세가격 예측을 낮추는 방향으로 작용하였다.

지역 Feature 역시 높은 중요도를 보였다.

강남구와 서초구 등은
전세가격 예측을 높이는 방향의 SHAP 값을 보였으며,
도봉구와 강북구 등은 낮추는 방향으로 나타났다.

또한 같은 자치구 내부에서도
법정동에 따라 SHAP 값의 차이가 확인되었다.


## 8.2 월세 모델

Feature 중요도 순위:

1. 임대면적
2. 보증금
3. 자치구
4. 건축연식
5. 시간추세

특히 보증금은 월세 모델에서
두 번째로 중요한 Feature로 나타났다.

보증금이 증가할수록
월세가격 예측을 낮추는 방향의 SHAP 패턴이 나타났다.

이는 H5 다중회귀분석에서 확인된
보증금과 월세의 조건부 음의 관계와 일관된 결과이다.

# 10. 핵심 Insight

이번 분석에서 가장 중요한 결과는 다음과 같다.

### 1. 지역은 서울 전세가격의 핵심 변수이다.

통계검정에서 자치구별 가격 차이의 효과크기가 크게 나타났으며,
XGBoost 및 SHAP에서도 지역 Feature가 높은 중요도를 보였다.

또한 같은 자치구 내부에서도 법정동별 가격 차이가 존재하였다.


### 2. 면적은 전세와 월세 예측에서 가장 중요한 Feature이다.

전세보증금과 전용면적 사이에는 비교적 강한 양의 관계가 있었으며,
SHAP에서도 전세와 월세 모두 가장 중요한 Feature로 나타났다.


### 3. 신축 프리미엄이 여러 분석 단계에서 반복적으로 확인되었다.

EDA, Spearman 분석, 다중회귀, SQL, SHAP 모두에서
건축연식이 오래될수록 가격이 낮아지는 방향의 관계가 관찰되었다.


### 4. 보증금과 월세의 관계는 단순 상관관계만으로 판단하기 어렵다.

전체 데이터를 단순 분석하면
보증금과 월세 사이에 약한 양의 관계가 나타났다.

그러나 면적과 지역을 통제하면
보증금이 높을수록 월세가 낮아지는 관계가 나타났다.

다중회귀, SHAP, PostgreSQL 분석에서도
동일한 방향이 확인되었다.


### 5. Tree 기반 모델이 선형 모델보다 높은 예측 성능을 보였다.

전세와 월세 모두
Random Forest와 XGBoost가 Ridge Regression보다 높은 성능을 보였다.

이는 서울 임대가격이 단순한 선형 관계보다는
지역, 면적, 건축연식, 보증금 등의 비선형 관계와
상호작용을 포함하고 있음을 시사한다.

# 11. 프로젝트 한계

본 분석에는 다음과 같은 한계가 존재한다.

첫째, 학군, 역세권, 교통 접근성, 단지 브랜드,
세대수, 재건축 가능성 등 일부 중요한 입지 및 단지 특성이 포함되지 않았다.

둘째, 2023~2025년이라는 비교적 짧은 기간만을 분석하였다.

셋째, 서울시 전월세 데이터는 접수 시점과 실제 계약 시점이 다를 수 있으므로
모든 시계열 분석에서 실제 계약일을 별도로 사용하였다.

넷째, 분석 결과는 관찰 데이터에서 나타난 관계이므로
통계적으로 유의한 관계를 직접적인 인과관계로 해석할 수 없다.

다섯째, XGBoost와 같은 Tree 기반 모델은
학습기간 이후의 장기적인 시장 추세를 선형적으로 외삽하는 데 한계가 있다.

# 12. 결론

서울 아파트 전월세 데이터를 분석한 결과,
임대가격은 지역, 전용면적, 건축연식 등
주택의 구조적 특성과 밀접한 관계를 보였다.

특히 전세가격에서는 지역과 면적의 영향이 크게 나타났으며,
건축연식 역시 다른 조건을 고려한 이후에도
가격과 유의한 음의 관계를 유지하였다.

월세시장에서는 전체 데이터의 단순 상관관계만으로는
보증금과 월세의 관계를 정확하게 설명하기 어려웠다.

면적과 지역 조건을 고려하고
다중회귀 및 머신러닝 모델 설명을 함께 수행한 결과,
보증금 증가와 월세 감소 사이의 관계가 반복적으로 확인되었다.

가격 예측에서는 XGBoost가 가장 높은 성능을 보였으며,

전세 모델:

- R² = 0.8403
- MAE = 9,074.27만원

월세 모델:

- R² = 0.7885
- MAE = 29.32만원

을 기록하였다.
